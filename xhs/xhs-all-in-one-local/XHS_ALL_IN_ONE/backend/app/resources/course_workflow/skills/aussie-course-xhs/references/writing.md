# 笔记、课程事实与资料卖点

## 最小证据链

分清四类依据：大学当前学期官方手册/课纲；实际成品及同版本QA；真实需求/本人后台数据；原创一般方法与合成示例。用户提供LMS信息可用，但尊重访问和传播权限。

声明台账可用：`claim_id / 类型 / 拟公开原句 / 状态 / source_ids / 学期或版本 / 定位 / 处理`。状态分已核实、待核实、推断；只有已核实且来源支持相同范围的客观事实，才能作公开确定性宣称。台账覆盖标题、正文和图片里的数字及承诺。

有来源不等于支持结论：旧学期课纲不能证明本学期题型；公开目录不能证明本产品有详解；同校不同课程不能互证。未核实的事实删除、缩小到证据支持的范围，或留在内部待确认列表，不用“我觉得”粉饰。

## 写作方式

叙述顺序由本篇问题决定，下面仅作可选方向。自测、错误对照、三点清单、长段落和购买引导都不是默认必备。检查整段是否反复出现同一开头、同样长短和硬凑三项；删重复时保留事实、单位、条件和自然语气。不要用虚构亲历或刻意碎句制造真人感。

中文为主，必要英文术语解释清楚。初稿正文通常150–450中文字符，按内容伸缩；这不是平台字数要求。标题以缩略可读和当前编辑器限制为准。通常3–8个相关话题，按学校/课程/学科/问题选择；不宣称固定数量提高推荐。

- **方法型**：具体表现 → 判断卡点 → 可执行步骤 → 自查/新题验证。
- **概念型**：常见混淆 → 条件/区别 → 原创小例子 → 适用边界。
- **资料型**：谁在哪个阶段 → 真实目录/样页 → 如何使用 → 不适合谁及版本。
- **Assignment型**：任务要求 → Rubric拆解 → 思路/结构判断 → 独立完成及学校要求。

不硬塞焦虑、故事或购买动作。提供一个完整有用的收获，不能把关键方法全藏在“评论领取”后。

正文和图片说明用内容名称衔接，例如“课程主线”“供需判断”“讲义样张”，不写“第几页”“PDF第X页”“2/6”“图5”等页序或源页定位。完整文档已有页码不需改掉；内部证据仍记录实际来源位置。已核实的资料总页数、题量、课程代码和方法步骤数字可以保留。

## 产品营销条件

- 看过真实最终文件和预览，确认学校、课程、适用学期/范围及版本。
- QA对应相同文件SHA-256，或已对当前文件重做核验；核心题目/答案/公式无已知错误。
- 宣传实际存在的组成和用法，不把计划中产品说成已交付，不虚构价格、优惠、库存、销量或评价。
- 只有PDF就写PDF；没有Word、视频或完整详解就不承诺。页数和目录不等于内容质量证明。
- 缺产品证据时继续真实学习方法或需求研究；商品化主张等证据齐备。

## 学术诚信与身份

使用独立学习辅助的真实身份。学校名用于准确描述适用对象，不暗示合作、大学官方或教师背书。不能为了素人感编造高分学姐、真实课堂照片、使用成果或聊天记录。

Assignment示例应原创、可公开、不替代当前评分任务。“仅供参考”不能包裹可提交成品；受限试卷/答案不能改称自编题。Cheat Sheet区分复习用途与允许带入考试的资料，未查当前规则不能说可带入考场。

`assets/brief.example.json`、`assets/packet.example.json`为合成方法示例，不代表任何真实学校、产品或发布结果。
