# 课程资料推广图文结构

这是用户于2026-10-24明确要求的默认推广结构；当次明确要求优先。参考图片仅学习信息层级与样页展示方式，不沿用其中学校Logo、竞争品牌标记、预测/提分承诺或考试信息。

当前默认采用用户已确认成品的 [参考风格](approved-style.md)。它优先于早期ANU参考图；其中课程、品牌与讲义仅为示例，每篇重新确认品牌和具体产品。

## 开始前确认两项

1. **本篇品牌**：准确名称，以及可用的真实Logo。星途、稳过、若优解不混用，也不由语音近似名称自动判断。先找已有品牌素材，查看后核对；没有真实资产时说明缺口，不擅自重画Logo或用其他品牌替代。
2. **本篇产品**：用户要卖/展示哪份讲义，大学、课程、学期、版本和实际Word/PDF路径。先列少量真实候选，可解释推荐理由；不把文件名当质量证明。

每篇新图文都先确认上述两项；本篇请求中已经明确给出的视为已确认，本篇改稿不再问同一问题。不能把其他笔记的选择自动带过来。确认后继续读取、核验和制作；推广授权不等于公开发布授权。

## 第一张封面

- 上部或主视觉明确写学校名称/简称和课程代码，例如“墨尔本大学 / UniMelb”与醒目的“ECON10004”。只用文字，整套不放学校Logo。
- 主标题对应本篇目的：讲义整体简介、资料组成、某个知识点或复习选题；不要每篇硬套同一主题。
- 可配多张所选资料的真实页面缩略图，帮助学生看见产品形态。数量按信息密度安排，例如单排4页或双排6页；用户要求封面多展示页面时沿用该选择，不固定只放2–3页。缩略图不是重新排版后冒充的Word/PDF页面。
- 底部统一放本篇已确认的品牌Logo，可用两侧细线组织页脚，不叠加学校Logo。

## 后续页面

- 用户于2026-10-24进一步明确：以后默认不再单独放考试安排页，包括全校考试周、SWOT Vac、考试日期/地点及考场提醒；发布正文也不机械补回日程段落。课程难点、复习方法、可考范围、题型等学习相关信息仍须核实后按当篇选题融入。用户当次明确要求考试安排时再制作。

- 用户于2026-10-24补充：参考图的成段文字同样重要。根据选题把课程简介、知识主线、重点/易混点、学习方法和讲义作用写进图片，不能只做截图陈列或短标签。不是每篇都填满所有栏目；让文字解决当篇学生问题。
- 可以安排一至数页有清楚段落的文字说明，按信息密度决定；保持手机阅读的字号与行距，不用整页小字模仿长图密度。发布正文是补充，不替代图内解释。
- 样页外部的文字说明应指出：正在看什么、它对应哪个卡点、读者下一步怎么练。只写来源能够支持的卖点。
- 后面默认按已确认风格展示所选Word/PDF的完整真实页面；局部放大可以补充解释，不替代完整样张。每幅图片负责一个展示目的，优先读清而非堆数量。
- 用户明确要求“整个PDF页面放进去”时，展示完整页面，保留页眉、正文、公式、图形及页码，外部说明与品牌页脚不遮挡原页。按原比例尽量放宽，减少外围重复边框和内边距；可调整竖版画布比例，让整页与品牌页脚一起放下。局部放大仅作为补充，不能继续替代用户要求的整页展示。
- 每页底部保持同一品牌Logo。不要把整套替换为原创知识卡而不展示用户选定的产品。
- 不强制模拟Word界面。可以把真实文档页面渲染为图片；对外可写“PDF讲义样张”或“Word讲义样张”，不能把PDF冒称Word软件截图。来源具体位置只在内部证据记录，不在图片或正文写“第几页”“PDF第X页”“2/6”“图5”等定位标记；原文档已有页码保持原样。
- 原文件保持不动。页面可放大、加框/说明和适度水印；不能偷偷改页面里的字、公式或品牌后继续声称未经修改的真实截图。
- 选必要样页或局部，不公开足以代替整份购买的章节，也不展示隐私/私有路径/未核实当期考核信息。源文件含其他品牌、学校Logo或明显问题时，换合适页面；若确需修订原产品则单独说明并按版本处理，不能用遮挡掩盖事实缺陷。

## 按目的组织讲解

讲义简介要用真实内容解释适合谁、怎样用；知识点选题要把判断条件或过程讲完整；练习产品要让学生看见题目与解析怎样支持独立训练。具体顺序、文字形式和样张数量由本篇目的决定，不从固定分镜表中轮换。未核实不写题量或预测命中。

组图数量随有效内容确定。参考图中的长图密度可借鉴，但缩略到手机仍须读清。

分镜从选题出发。比如“供需图看懂但换题不会画”需要读题判断与迁移练习；“入门预习顺序”需要课程主线与先修自查。课程难点是有依据的教学判断时，写成易混点或学习建议，不冒称官方考试重点或全体学生统计。

## 根据选题选样张

先说清所选样张对应的问题、值得观察的内容和可以继续练习的动作，再决定数量。局部重点放大与整页展示配合；不是所有产品都需要相同样张数，也不需要为展示丰富而混入与主题无关的章节。正文中的课程简介、重难点和讲义介绍按选题需要安排，不组成固定栏目表。
