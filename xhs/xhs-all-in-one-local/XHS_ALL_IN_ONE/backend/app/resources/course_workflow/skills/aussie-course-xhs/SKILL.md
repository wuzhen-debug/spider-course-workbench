# 澳洲课程资料小红书运营

面向澳洲大学中国留学生，把一门课的真实学习难点、下一步学习动作和资料使用方法讲清楚。交付可审阅的原创内容；规则检查降低风险，不保证爆款、推荐或百分之百过审。

## 先识别本次任务

- **选题**：读 [学生需求与选题](references/topics.md)，交付候选与依据，不自动扩成全部笔记。
- **课程资料推广图文**：先读 [已确认参考风格](references/approved-style.md) 和 [产品展示结构](references/product-showcase.md)，每篇先确认本篇品牌与所展示讲义，再读写作、视觉参考。
- **明确只做知识科普**：读 [写作与事实核验](references/writing.md)，需要图片时再读 [封面与组图](references/visuals.md)。
- **只做封面**：沿用已确认文案和品牌，读视觉参考；不顺带重写全文。
- **合规检查**：读 [合规复核](references/compliance.md)，检查实际收到的内容面；先给定位到原句的修改建议。
- **改稿 / 复盘**：读 [改稿与审阅](references/revisions.md)，优先局部修正，保留已确认部分。

每篇新推广图文开始前，先让用户确认本篇品牌及Logo、具体讲义及学期/版本/文件。用户在本篇请求中已经明确给出两项即为确认，不机械重复；其他笔记曾用过的品牌或讲义不能自动视为本篇确认。同一篇的局部改稿沿用本篇已确认选择。除此之外，只有学校归属、产品事实、版权或关键目标存在实质歧义时再集中问最少的问题；继续不依赖答案的工作。

在本业务语境下，收到“某大学＋课程代码，做一篇图文”而未明确只做科普时，默认准备课程资料推广：先确认本篇使用哪个品牌及哪份真实讲义，收到回答后再开始依赖这些选择的制作。已保存的风格可直接复用，示例里的墨大、ECON10004、星途和2026S2产品不作为未来笔记的默认身份或产品。

## 三种内容路径

1. **通用学习方法**：可从零资料开始，用原创示例说明可执行方法。无须先造一套课程产品。不得捏造个人经历或具体课程要求。
2. **具体课程解析**：先核对大学 + 课程代码 + 课程名称 + 当前学期；同码不代表同校同课。缺少本学期证据的范围、题型、日期、权重、hurdle、AI规定不得写成现行事实。
3. **资料成品推广**：实际读取拟推广文件、样页和对应版本的 QA 证据。每个组成、页数、题量、答案、语言和适用范围卖点都要可核验。成品未完成、QA未通过或版本不匹配时，先完成可行的资料核验；可并行做不含产品宣称的学习内容，但不能把产品营销包标成可发布。

技能创建、笔记草稿、内容 QA、营销审阅和公开发布分别记状态。用户授权创建本技能，不等于批准未来某篇笔记或开放账号操作。

## 编辑原则

制作或处理“太模板化”的反馈时，先读 [内容编辑判断](references/editorial.md)。参考稿固定视觉身份与展示要求，不固定开头、栏目、篇幅或图片顺序。自测、错误对照、课程介绍和公式放大均按内容选用；不把一次改稿变成以后每门课的必备栏目。

## 工作流程

### 1. 明确任务与读者收获

内部明确：当前问题及其依据、读完能做什么、本篇增加的信息、讲义怎样支持、输出范围和品牌。只填写有用的已知信息，不强制填表或增加确认。需要结构记录时参考 [brief.example.json](assets/brief.example.json)。

以“一门课 + 一个主题/产品 + 一个学生能理解的价值”为最小内容单元。推广图文先确认品牌和产品，不用中性栏目替代用户品牌来跳过确认，不混用稳过、星途、若优解，也不虚构学生或学校官方身份。明确无品牌科普任务才可采用中性栏目。

### 2. 产出有差别的选题与标题

先选学生问题，再组织资料宣传。写清这篇给谁看、在哪个学习阶段、卡在哪一步、点开后能得到什么，以及选定讲义有哪些真实内容可以接住这个问题。不要把产品名称直接当作唯一选题；缺站内数据时可以做有依据的待测选题，不称已验证爆款。详细判断见学生需求与选题。

比较有实质差异的选题后选择最合适的一种。标题服务本篇收获，不固定三个角度或句式；用户要求选题备选时再交备选。数字必须兑现，关键词自然出现，数量不当作算法规则。

有平台研究时，保存来源、日期、样本范围、可见互动与学生原问题。公开搜索线索不等于站内全量热榜；缺失数据记为未知，不补零，不编造“学生都在问”。资料/试读/价格的真实询问与泛泛点赞分开记录。

### 3. 让关键选择可审阅

已保存的参考风格是后续课程图文的默认起点，不为换一门课重新发起两版封面选择。仅用户要求探索新风格、或本篇没有适用风格时，再提供有布局差别的封面小样。选题与课程内容仍需针对本篇重新判断；能出图就出真实预览，只有文字方案时明确标“待渲染”。

若用户要求“先选再做”，在这一具体选择点等待；若已选好标题/风格，或要求“直接生成”，沿用选择完成整套待审稿，不为关键词、每张内页等重复设确认门。已知资料足够时先把工作做到可审阅，不把例行判断交回用户。

### 4. 写出有用、可核验的笔记

标题提出的收获须由正文和图片兑现。根据知识关系选择过程、图形、反例、数据分析或真实样张批注，让条件与结论清楚。一篇讲清一个问题；不强制统一段落顺序或先写长文再拆图。

站在学生角度表达，不冒充学生。把客观课程事实、产品事实、统计与效果宣称记入声明台账，链接到来源或文件页码。未经核实的事实不能通过改成“我觉得”继续误导。

Assignment 只做要求解析、Rubric理解、思路、结构和独立练习。禁止承接或宣传代写、代考、正在评分作业的可提交成品、泄露考试答案。合规提示不能使违规主体内容变安全。

### 5. 制作封面与内页

默认不单设考试安排页，也不在正文补回日程段落；课程难点与已核实的考核要求仍按选题融入讲解，详见[产品展示结构](references/product-showcase.md)。

课程资料推广保留学校/代码封面、图内解释和真实完整样张，具体编排由当篇问题决定。课程简介、重点与易混点、学习方法和讲义作用按选题取舍，写成图片上的完整句子和必要段落，不能只放宣传标签或把全部解释留在发布正文。封面醒目展示学校文字和课程代码，整套不使用学校Logo；每页底部统一放已确认品牌的真实Logo。真实Word/PDF样页配外部讲解，说明它解决什么问题、怎样使用。详细分镜与用户参考图见产品展示结构。

默认沿用已确认参考版的1080×1620竖版、蓝橙配色、宽正文、多样页封面和完整讲义展示；具体参数见参考风格。按信息量和样张用途决定组图数量，不凑满固定数量；不复制上一门课的叙述和图片编排。完整图文同时交付实际PNG/JPG、可编辑源文件或提示词和缩略总览；内部文件可排序，图片、正文与图片说明不另加“第几页”“PDF第X页”“2/6”“图5”等定位标记。原讲义自带的页码保持原样，来源定位保存在内部证据中。

精确课程代码、中英文术语、公式和表格优先确定性排版；需要插画/概念视觉时调用环境已有的原生 imagegen，并遵守其编辑规则。无须安装本次研究的全部外部工具。纯文字模板不强行生图，复杂教学图也不强行塞进纯文字卡。

先对照近期稿检查内容是否可互换，再逐张检查文字、公式、来源、标题兑现、版权与手机可读性。自动尺寸/溢出检查不能代替实际看图。公式错误应修正源内容并重渲染；不得伪造拍摄的学生课堂笔记、学校标志或成绩截图。

### 6. 复核并交付

按合规参考区分社区内容、商业合作、商品和付费广告的适用规则。检查标题、正文、话题、图片文字与画面；若涉及评论、简介或购买入口，也一并检查。未检查的内容面如实列明。

默认交付：选定标题、正文/话题、实际图片、来源与检查状态；按需要提供备选和源文件。跨课程或较大改稿同时记录与近期稿的实质区别。主回复展示关键成果，不堆工程字段。

复杂、涉及产品宣称或多轮批准的任务可使用 [packet.example.json](assets/packet.example.json) 记录版本，并运行：

```bash
python3 scripts/review_packet.py /absolute/path/packet.json
```

该脚本只检查本地结构、证据链接、已声明文件哈希和批准是否绑定当前内容；不判定文案语义、图片质量或平台能否过审。它不会写批准记录、登录、上传或发布。

### 7. 根据反馈局部改稿

记录本轮改动与原因，修改正文时同步受影响的封面/内页与证据；保留旧版本。不把一次偏好固化为长期规则。用户明确要求保存成长期规则时，才修改本技能或指定账号配置；不自动写入全局记忆。

## 事实、权限与交付边界

- 面向发布的合规复核应刷新当前官方依据，记核验日期、原始链接与适用范围。普通草稿或局部改稿可沿用已查依据并标待复核，不因例行文字修改重启整套调研；读不到规则时如实说明，不能把历史库或关键词扫描冒充当前官方审核。
- 不声称官方推荐权重、账号官方分数、保证收益、必考/押题命中、包过保分。已确认品牌名称中的字词需结合上下文判断，不做单词定罪。
- 不复制竞品独特文案、故事或图；不删他人水印装原创；真实学术材料只展示有权公开的必要样页，隐去学生隐私，不暴露私有路径、完整原件下载链接或带会话参数的URL。
- 首次向新的外部 AI/设计服务传送课程原文件、学生作业或受限材料前，说明接收方、范围和处理边界并取得授权；已有明确授权按范围复用。优先只发送审核后的封面文案与原创示例。
- 创建或改稿不自动登录、发布、发私信、回复评论、投广告、上传客户数据或改生产系统；这些动作另按用户当次明确授权执行。
- 默认输出到本任务文件夹，不写进技能目录、不改网站代码、不移动旧归档。生成营销 PNG 不触发题库课程成品归档；若任务另有课程 PDF/Word 成品，遵循用户现有题库保存规则。

本技能为原创行业整合，方法来源与未采用部分见 [设计来源](references/sources.md)；无需依赖这些第三方 Skill 才能运行。
